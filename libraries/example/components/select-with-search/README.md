# Select mit Suche · 0.2.0

Feste Auswahl mit separatem Suchfeld im Picker. Der ausgewählte Wert bleibt nicht editierbar; Suchtext ist niemals Formularwert. Nur vorhandene aktivierte Schlüssel werden übernommen, bereits innerhalb der Komponente und nicht erst durch einen nachträglichen Validator.

CEM führt die Schnittstelle, DTCG/CSS das Aussehen, SCXML den Zustand und HTML/ARIA die Semantik. Die Hostprojektion in accessibility.rules.json beschreibt zusätzlich Fokus, Tastatur und Formularintegration. Diese aktive Beispieldefinition ist im begrenzten Quellen-/SCXML-Profil prüfbar, kein bereits qualifiziertes Laufzeitpaket.
