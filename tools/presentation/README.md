# Native Präsentation

[Layoutregeln, Aufruf, Quellschutz und Grenzen](../../docs/presentation/README.md).

`present.mjs` liest eine vorhandene FIG und schreibt eine neue FIG, ein PNG und ein Receipt. `layout.mjs` enthält die gemeinsamen Darstellungsregeln; keine neue JSON-Sprache. Forschungseingaben und frühere Outputs werden nicht überschrieben.
