# Select mit Suche · Kandidat

Feste Auswahl mit separatem Suchfeld im Picker. Der ausgewählte Wert bleibt nicht editierbar; Suchtext ist niemals Formularwert. Nur vorhandene aktivierte Schlüssel werden übernommen, bereits innerhalb der Komponente und nicht erst durch einen nachträglichen Validator.

CEM führt die Schnittstelle, DTCG/CSS das Aussehen, SCXML den Zustand und HTML/ARIA die Semantik. Die Hostprojektion in accessibility.rules.json beschreibt zusätzlich Fokus, Tastatur und Formularintegration. Dies ist eine neue Forschungsdefinition, kein bereits qualifiziertes Laufzeitpaket.
