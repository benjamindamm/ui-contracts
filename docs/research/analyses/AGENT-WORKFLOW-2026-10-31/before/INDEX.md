# Erhaltene Ausgangsdateien

Die Root-README wurde nach einer Namenskollision mit dieser Archivübersicht aus der vorhandenen Arbeitskopie und dem dokumentierten letzten Zusatz rekonstruiert; README-provenance.json benennt die Beleggrenze.
